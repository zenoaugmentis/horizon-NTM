# S05 · Воспроизведение и размещение файлов

Это обновлённый комплект для слияния с репозиторием, не полный репозиторий.
Пути внутри архива уже соответствуют целевым путям: docs/specs, docs/reports,
tools и tests. Файлы с теми же именами заменить; остальные файлы проекта сохранить.
Корневые README-S05.md и PR-S05.md не создаются.

## Автоматическая проверка

Из корня репозитория, Python 3.10+, стандартная библиотека:

```powershell
python -m unittest discover -s tests -p "test_probe_s05.py" -v
```

## Генерация

Базовые два пака:

```powershell
python tools/probe_s05.py packs --output .local/s05-basic
```

Дополнительные ZIP и папочные паки:

```powershell
python tools/probe_s05.py extended --output .local/s05-extended
```

Использовать свежий каталог: генератор отказывается заменять существующие пакеты.
Содержимое s05-extended скопировать в resourcepacks эталонной установки.
Имена паков сопоставлены с матрицей E04–E17 в ручном отчёте.
Включать только нужный пак поверх Default; порядок проверять по последней строке
Reloading ResourceManager. Новая генерация проверена автоматически, но её результаты
не запускались заново в моей установке Minecraft. Хеши первоначальных архивов для этих файлов не приводятся.
S05-sidecar-control — новый контроль, не точная копия исходного C и не завершённый опыт.
Для него результат остаётся неизвестным. A/B также воспроизводят роли, не точные байты исходных архивов.

## F3+T и alpha

Включить S05-reload-folder: сначала камень жёлтый, яблоко синее.
Оставив игру запущенной, выполнить (путь одной строкой):

```powershell
python tools/probe_s05.py mutate --folder "$env:USERPROFILE\Documents\horizon-reference\resourcepacks\S05-reload-folder" --action stone-magenta
```

Нажать F3+T: камень должен стать пурпурным, яблоко остаться синим.
Для полупрозрачности в том же папочном паке:

```powershell
python tools/probe_s05.py mutate --folder "$env:USERPROFILE\Documents\horizon-reference\resourcepacks\S05-reload-folder" --action apple-alpha128
```

После F3+T сравнить инвентарь и вид в руке. Для alpha=0 выбрать S05-item-alpha.zip.
Не путать этот ZIP с изменяемым папочным паком.

## Tint

Выбрать S05-tint-folder: сравнить белые верхние грани камня и травы.
Затем выполнить и нажать F3+T:

```powershell
python tools/probe_s05.py mutate --folder "$env:USERPROFILE\Documents\horizon-reference\resourcepacks\S05-tint-folder" --action grass-red
```

Сравнить верх травы, боковую травяную часть, землю и камень с E17.
Команда mutate намеренно перезаписывает один файл указанного папочного пака.
ZIP при запущенном клиенте не перезаписывать в рамках этих проверок.

## Что коммитить

Коммитить файлы этого комплекта, включая собственный скриншот и нормализованные
фрагменты журнала. Не добавлять генерируемые ZIP, игровые ресурсы, JAR, миры,
полные приватные логи и __pycache__/*.pyc. Каталог .local — только локальные результаты.
Скриншот я сделал во время проверки; игровых текстур из JAR комплект не извлекает.
